# AIDE 桌面伴侣方案 — Win7环境

> 状态：方案设计，待评审可行性

## 1. 需求描述

- 启动后隐藏CMD黑框，防止用户误关
- 桌面右下角有可交互的入口图标（自定义头像/名字）
- 点击图标弹出小对话窗口（基本对话功能）
- 小窗口有"全屏"按钮，展开为完整功能页面
- 全屏可缩回小对话窗口
- 增加用户粘性（自定义头像、名字、动画）

## 2. 环境约束

| 约束 | 说明 |
|------|------|
| 操作系统 | Windows 7 SP1 (64位) |
| Python | 3.8.10 embedded（精简版，无tkinter、无pip） |
| 包管理 | 只能解压.whl到site-packages |
| PySide6 | 不支持Win7 |
| 现有依赖 | Pillow 10.4.0 已安装 |

## 3. 推荐方案：pystray托盘 + Chrome --app

### 3.1 整体架构

```
start.bat (启动入口)
  │
  ├─ pythonw.exe 启动后端服务（无黑框）
  │
  └─ pythonw.exe 启动 tray_companion.py（托盘伴侣）
       │
       ├─ pystray 系统托盘图标（右下角）
       │    ├─ 单击：打开小对话窗口
       │    └─ 右键：全屏 / 设置 / 退出
       │
       └─ 调用 Chrome --app 模式打开窗口
            ├─ 小窗口模式：400x600，仅对话功能
            └─ 全屏模式：1024x768，完整功能
```

### 3.2 各组件说明

#### A. 隐藏CMD黑框
- 用 `pythonw.exe` 替代 `python.exe` 启动uvicorn
- embedded Python自带 `pythonw.exe`
- 不创建任何控制台窗口

#### B. 系统托盘（pystray）
- **图标**：默认使用 🧭 风格的PNG图标，用户可自定义
- **Tooltip**：显示"知行 - AIDE v0.3.0"（名字可自定义）
- **左键单击**：弹出小对话窗口
- **右键菜单**：
  - 打开小窗
  - 打开全屏
  - 检查更新
  - 修改配置
  - 重启服务
  - 退出
- **状态指示**：图标颜色变化（绿色=运行中，红色=异常）

#### C. 小对话窗口（Chrome --app模式）
```
Chrome启动参数：
--app=http://127.0.0.1:8900/chat?mode=mini
--window-size=400,600
--window-position=bottom-right
```
- 无地址栏，看起来像原生桌面应用
- 仅显示对话功能区域
- 底部有 [⛶ 全屏] 按钮

#### D. 全屏模式
```
Chrome启动参数：
--app=http://127.0.0.1:8900/
--start-maximized
```
- 完整功能页面，与当前Web界面一致
- 导航栏多一个 [缩小] 按钮回到小窗口

#### E. 用户自定义
- **头像**：PNG图片替换托盘图标（data/avatar.png）
- **名字**：在设置页面修改，同步更新托盘tooltip和窗口标题
- **动画**：web端CSS呼吸动画/弹跳效果（小窗口的头像区域）

### 3.3 需要新增的依赖

| 包 | 版本 | 大小 | 类型 | 说明 |
|----|------|------|------|------|
| pystray | 0.19.5 | ~50KB | pure Python | 系统托盘 |
| six | 1.16.0 | ~15KB | pure Python | pystray依赖 |

> Pillow已有，无需额外安装。两个whl都是纯Python，解压即用。

```
aide/
├─ app/backend/
│  ├─ static/              ← 新增 mini模式页面样式
```

### 3.5 启动流程

```batch
@echo off
:: start_silent.bat - 无黑框启动

:: 1. 用pythonw启动后端（无控制台窗口）
start "" pythonw.exe -m uvicorn main:app --host 127.0.0.1 --port 8900

:: 2. 等待后端就绪
:wait
pythonw.exe -c "import httpx; httpx.get('http://127.0.0.1:8900/api/health')" 2>nul
if errorlevel 1 timeout /t 2 >nul & goto wait

:: 3. 启动托盘伴侣
start "" pythonw.exe companion/tray_companion.py
```

## 4. 备选方案

### 方案A：捆绑Chromium便携版（推荐）

**核心思路**：离线包自带Chromium便携版，不依赖用户系统浏览器。

| 项目 | 说明 |
|------|------|
| 浏览器 | Chromium 109.x（最后支持Win7的开源版本） |
| 大小 | ~120MB |
| 来源 | chromium.cypress.io 或 Chromium官方snapshots |
| 安装 | 直接拷贝，无需安装 |
| 许可 | 开源BSD协议，无商业风险 |

**离线包新增目录**：
```
aide-win7-offline/
├── aide/                    ← 应用代码
├── python/                  ← embedded Python
├── chromium/                ← 新增：便携Chromium
│   ├── chrome.exe
│   ├── chrome.dll
│   └── ...（~120MB）
├── packages/                ← pip whl包
└── install.bat
```

**体积对比**：
| 方案 | Win7包大小 | Win10包大小 |
|------|-----------|-----------|
| 当前（无浏览器） | 91MB | 331MB |
| +Chromium便携版 | ~210MB | ~530MB |

**调用示例**：
```python
import os, subprocess
ROOT = os.path.dirname(os.path.abspath(__file__))
CHROME = os.path.join(ROOT, 'chromium', 'chrome.exe')

def open_mini_chat():
    subprocess.Popen([CHROME,
        '--app=http://127.0.0.1:8900/chat?mode=mini',
        '--window-size=420,640',
        '--window-position=9999,9999',  # 右下角
        '--no-first-run',
        '--disable-default-apps',
        '--disable-background-networking',
    ])

def open_fullscreen():
    subprocess.Popen([CHROME,
        '--app=http://127.0.0.1:8900',
        '--start-maximized',
        '--no-first-run',
    ])
```

**优点**：
- ✅ 彻底解决浏览器依赖问题
- ✅ --app模式无地址栏，体验像原生应用
- ✅ 开源无许可风险
- ✅ 完全兼容Vue3前端
- ✅ 和PySide6桌面客户端共用同一套Chromium

**缺点**：
- ❌ 包体积增加~120MB
- ❌ 需要单独维护Chromium版本

### 方案B：pywin32-ctypes 原生窗口
- 用 `pywin32-ctypes`（纯Python whl）调用Win32 API
- 创建无边框透明窗口，实现桌面浮动头像
- 优点：真正的桌面悬浮效果
- 缺点：开发量大（约500-800行），需要处理窗口消息循环、透明度、拖拽等
- 风险：Win7 embedded Python下ctypes调Win32 API的兼容性需验证

### 方案C：Electron/Tauri桌面应用
- 优点：UI最灵活，动画效果最好
- 缺点：体积大（Electron 100MB+），Win7兼容性差，离线部署困难
- 不推荐

### 方案D：混合方案（方案A + 系统浏览器回退）
- 自带Chromium优先使用
- 如果Chromium目录不存在（比如用户删除了），回退检测系统浏览器
- 检测顺序：系统Chrome → Firefox → 默认浏览器 → 提示安装
- 最稳健的方案

## 5. 浏览器兼容性方案（重点）

### 5.1 各浏览器能力对比

| 浏览器 | 应用窗口模式 | ES6/Vue3渲染 | Win7可用 | 部署难度 |
|--------|-------------|-------------|---------|---------|
| Chrome | `--app` 模式 ✅ | ✅ | ✅ (≤109) | 离线包需捆绑 |
| Firefox | 无应用窗口模式 ❌ | ✅ | ✅ (ESR) | 用户可能已安装 |
| Edge | `--app` 模式 ✅ | ✅ | ❌ | - |
| IE9/10/11 | mshta HTA ❌ | ❌ | ✅ | 不兼容Vue3 |
| 默认浏览器 | webbrowser.open | ✅ | ✅ | 零依赖 |

### 5.2 浏览器检测优先级

```
检测顺序：
  1. Chrome → 用 --app 模式（最佳体验，无地址栏）
  2. Firefox → 用 -new-window 打开（有地址栏但可用）
  3. 系统默认浏览器 → webbrowser.open（兜底）
  4. 都没有/只有IE → 提示用户安装Firefox
```

### 5.3 Win7常见场景分析

| 场景 | 概率 | 浏览器 | 应对 |
|------|------|--------|------|
| 内网办公电脑（主流） | 60% | IE9/10 + 可能有Firefox | 提示安装Firefox |
| 开发人员电脑 | 20% | Chrome | 直接用 --app |
| 国产浏览器（360/搜狗） | 15% | Chrome内核 | 尝试 --app |
| 只有IE | 5% | 无 | 强制提示安装 |

### 5.4 检测逻辑伪代码

```python
import subprocess, os, winreg

def find_browser():
    """按优先级查找可用浏览器"""
    # 1. 查Chrome
    chrome_paths = [
        os.path.expandvars(r'%PROGRAMFILES%\Google\Chrome\Application\chrome.exe'),
        os.path.expandvars(r'%PROGRAMFILES(X86)%\Google\Chrome\Application\chrome.exe'),
        os.path.expandvars(r'%LOCALAPPDATA%\Google\Chrome\Application\chrome.exe'),
    ]
    for p in chrome_paths:
        if os.path.exists(p):
            return ('chrome', p)

    # 2. 查Firefox
    ff_paths = [
        os.path.expandvars(r'%PROGRAMFILES%\Mozilla Firefox\firefox.exe'),
        os.path.expandvars(r'%PROGRAMFILES(X86)%\Mozilla Firefox\firefox.exe'),
    ]
    for p in ff_paths:
        if os.path.exists(p):
            return ('firefox', p)

    # 3. 查360/搜狗等Chrome内核浏览器（通过注册表）
    try:
        key = winreg.OpenKey(winreg.HKEY_LOCAL_MACHINE,
            r'SOFTWARE\Microsoft\Windows\CurrentVersion\App Paths\chrome.exe')
        path, _ = winreg.QueryValueEx(key, '')
        if os.path.exists(path):
            return ('chrome', path)
    except:
        pass

    # 4. 兜底
    return ('default', None)

def open_app_window(url, mode='mini'):
    browser, path = find_browser()
    if browser == 'chrome':
        if mode == 'mini':
            subprocess.Popen([path, f'--app={url}?mode=mini',
                '--window-size=420,640', '--window-position=9999,9999'])
        else:
            subprocess.Popen([path, f'--app={url}', '--start-maximized'])
    elif browser == 'firefox':
        subprocess.Popen([path, '-new-window', url])  # 有地址栏，但不影响使用
    else:
        import webbrowser
        webbrowser.open(url)
```
