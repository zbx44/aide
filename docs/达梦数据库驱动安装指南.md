# 达梦数据库驱动（dmPython）安装指南

## 概述

AIDE 的数据库查询功能依赖达梦官方 Python 驱动 **dmPython**。该驱动不支持 pip 在线安装（不在 PyPI 上），需要手动部署。

数据库功能为**可选模块**，不安装 dmPython 不影响其他功能正常使用。

---

## 安装步骤

### 1. 获取驱动文件

从达梦官网下载 dmPython 驱动包：

- 下载地址：https://eco.dameng.com/download/ → DM 驱动 → dmPython
- 选择与你的 **Python 版本 + 操作系统** 对应的包

> **注意匹配：**
> - Win10 离线包用 Python 3.12 → 下载 cp312 版本
> - Win7 离线包用 Python 3.8 → 下载 cp38 版本
> - 如果官网没有对应版本的预编译包，需要在本机编译

### 2. 安装方式

#### 方式一：whl 文件安装（推荐）

```bash
# 将下载的 .whl 文件放到 packages/ 目录
pip install packages/dmPython-xxx.whl

# 或指定完整路径
pip install D:\downloads\dmPython-2.x.x-cp312-cp312-win_amd64.whl
```

#### 方式二：源码编译安装

```bash
# 解压 dmPython 源码包
cd dmPython
python setup.py install
```

> 编译需要：
> - C 编译器（Windows 用 Visual Studio Build Tools）
> - 达梦客户端库（dmcli），需设置环境变量 `DM_HOME` 指向达梦安装目录

### 3. 验证安装

```python
python -c "import dmPython; print('dmPython 安装成功')"
```

如输出 `dmPython 安装成功` 则安装完成。

## Windows 常见问题

### 问题1：DLL 加载失败

**现象：** `ImportError: DLL load failed while importing dmPython`

**原因：** 缺少达梦客户端运行时 DLL

**解决：**
1. 安装达梦客户端（dmcli），或从服务器上拷贝以下 DLL 到 `C:\Windows\System32\`：
   - `dmclient.dll`
   - `dmdpi.dll`
   - `dmcvt.dll`
2. 或将达梦客户端 `bin/` 目录加入系统 `PATH` 环境变量

### 问题2：加密算法加载失败

**现象：** `[-70028]:加密算法加载失败`

**解决：** 确保达梦客户端版本与 dmPython 版本一致，重新安装客户端

### 问题3：Win7 兼容性

Win7 + Python 3.8 环境下，使用达梦提供的 cp38 版本即可。
如有问题，尝试使用较旧的 dmPython 2.3 版本。

## 配置数据库连接

安装完成后，在 `user/user.env` 中配置连接信息：

```env
# 达梦数据库
DM_HOST=192.168.1.10
DM_STANDBY_HOST=192.168.1.11
DM_PORT=5236
DM_USERNAME=dmdb
DM_PASSWORD=你的密码
DM_DATABASE=lczx
```

> `user/user.env` 优先级高于 `config/default.env`，升级时不会被覆盖。

| 数据库连接测试 | 测试连通性 | ✅ |
