# AIDE 智能助手 - 用户操作手册

> 版本：v0.3.0  
> 日期：2026-05-24

---

## 一、快速开始

### 1.1 安装

1. 将离线包文件夹拷贝到目标电脑（如 `D:\aide`）
2. 双击 `install.bat` 等待安装完成
3. 安装完成后会自动生成 `start.bat`

### 1.2 启动

- **Win10**: 双击桌面图标 或 运行 `start.bat`
- **Win7**: 双击 `start.bat`
- 启动后浏览器自动打开 `http://127.0.0.1:8900`
- 如果没有自动打开，手动在浏览器输入上述地址

### 1.3 首次配置

首次使用需要配置大模型：

1. 点击左侧菜单 `设置`
2. 选择Provider（推荐腾讯TokenHub）
3. 填入API Key
4. 点击 `保存所有配置`
5. **重启后生效**：关闭CMD窗口重新运行 `start.bat`

## 二、核心功能

### 2.1 智能对话

- 左侧 `对话` 页面是主界面
- 输入消息按 Enter 发送，Shift+Enter 换行
- 支持思考模式（AI会展示推理过程）
- 支持流式输出（实时看到AI回复）

**上传附件：**
- 点击输入框右侧 📎 按钮上传文件
- 支持：Word、Excel、PPT、PDF、图片、TXT、CSV、JSON、YAML
- 文件内容会作为上下文辅助AI回答

**选择知识库：**
- 输入框上方的知识库下拉框
- 选择后AI会基于知识库内容回答问题（RAG）

### 2.2 本地文件搜索

**首次使用需添加索引目录：**
1. 对话中输入：`添加索引目录 D:\工作文件`
2. 系统自动后台创建向量索引
3. 之后可以自然语言搜索：

| 你说的话 | AI的操作 |
|---------|---------|
| 搜一下有没有2023年的报表 | 搜索文件，筛选2023年 |
| 找一下关于发动机的PPT文件 | 搜索文件名语义匹配，筛选PPT |
| 有没有存放合同的文件夹 | 搜索目录名 |
| 浏览D:\工作文件目录 | 列出目录内容 |

**支持的搜索语法（自然语言即可，不需要记）：**
- 时间：去年、今年、2023年、6月、这个月、上个月
- 类型：Excel、表格、Word、文档、PPT、图纸、CAD、代码、压缩包、图片、视频
- 条件：文件、文件夹/目录

### 2.3 文档生成

1. 左侧点击 `文档`
2. 描述你想要生成的文档内容
3. AI自动生成Word/Excel/PPT
4. 生成完成后点击下载链接

**示例：**
- "帮我生成一份设备运行月报，包含设备名称、运行时长、故障统计"
- "生成一个绩效考核表Excel，包含姓名、部门、得分、等级"
- "做一个项目汇报PPT，主题是数字化转型阶段性成果"

### 2.4 数据分析与查询

1. 左侧点击 `查数据`
2. 用自然语言描述你想查的数据
3. AI自动转换为SQL查询数据库
4. 结果以表格和图表形式展示

**前置条件：** 需要在设置页面配置数据源（达梦/MySQL/PostgreSQL/SQLite）

**示例：**
- "查一下本月设备故障次数"
- "统计各部门的维修工时"
- "对比去年和今年的产量趋势"

### 2.5 定时任务

1. 左侧点击 `任务`
2. 设置定时分析任务
3. 到点自动执行查询+分析
4. 结果可通过邮件/QQ推送

## 三、进阶功能

### 3.1 技能管理

- 左侧点击 `技能` 查看所有可用技能
- 可以开启/关闭不需要的技能
- 系统工具（如读文件、写文件）不可关闭

### 3.2 记忆系统

- 对话中点击输入框工具栏的 `记忆` 按钮查看
- **长期记忆**：AI自动记住你的姓名、偏好、工作规则等
- **对话摘要**：自动总结对话要点，下次对话AI能记住之前聊过什么

### 3.3 自我进化

- 点击 `进化` 查看AI的自我反思记录
- AI会根据对话中的反馈自动积累改进规则
- 也可以手动输入改进指令，如"回答更简洁""记住我喜欢表格格式"

### 3.4 知识库

1. 左侧点击 `知识库`
2. 创建知识库并上传文档（Word/PDF/TXT/Markdown）
3. 文档会被自动分块和索引
4. 对话时选择知识库，AI会基于文档内容回答

### 3.5 报表模板

1. 左侧点击 `模板`
2. 选择预设模板（设备运行月报、维修工作总结等）
3. 填写参数，AI自动生成文档
4. 也可以创建自定义模板

### 3.6 智能体广场

1. 左侧点击 `智能体`
2. 配置FastAGI平台的APP_ID和SECRET_KEY
3. 调用滴普平台的工作流能力

## 四、配置说明

### 4.1 大模型配置

| Provider | 适用场景 | API地址 |
|----------|---------|---------|
| 本地vLLM | 内网有GPU服务器 | http://你的服务器:8004/v1 |
| 腾讯TokenHub | 有外网环境 | https://api.lkeap.cloud.tencent.com/plan/v3 |
| OpenAI兼容 | 其他OpenAI格式服务 | 自定义 |
| 自定义 | 特殊API | 自定义 |

### 4.2 数据源配置

1. 设置 → 数据源配置 → 添加
2. 选择数据库类型（达梦/MySQL/PostgreSQL/SQLite）
3. 填写连接信息
4. 点击 `测试` 确认连接成功

### 4.3 用户配置文件

- 位置：`user/user.env`
- 优先级高于 `config/default.env`
- 升级时不会被覆盖

## 五、常见问题

### Q: 启动后浏览器没自动打开？
A: 手动在浏览器输入 `http://127.0.0.1:8900`

### Q: 切换对话时很卡？
A: v0.3.0已修复此问题，请确认使用最新版本

### Q: AI不调用工具，直接回答无关内容？
A: v0.3.0已优化系统提示，如仍有问题，尝试在问题中更明确（如"搜索文件xxx"而非"有没有xxx"）

### Q: 对话摘要是空的？
A: v0.3.0已改为6条消息后自动生成摘要，聊几轮后就会出现

### Q: 长期记忆也是空的？
A: 需要多聊几轮后AI才会自动提取记忆。打开记忆面板默认会展示所有已有记忆

### Q: 如何修改AI的名字和头像？
A: 目前可修改系统配置文件中的名字，自定义头像功能计划在桌面伴侣版本中实现

### Q: Win7不支持桌面客户端？
A: Win7不支持PySide6，目前只能通过浏览器访问。桌面伴侣方案（系统托盘+Chromium便携版）正在设计中
