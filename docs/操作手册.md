## 1. 产品简介

**AIDE**（AI Desktop Engine）是一款运行在本地的个人AI助手，专为航空发动机维修工厂的数字化办公场景设计。通过自然语言对话，即可完成文档撰写、数据分析、OA流程发起、定时报告生成等工作。

### 核心特点

| 特点 | 说明 |
|------|------|
| 🔒 本地优先 | 所有数据不出本机，LLM调用走内网vLLM |
| ⚙️ 配置驱动 | 分析任务模板化，SQL/Prompt/输出模板可配置复用 |
| 🧠 智能进化 | 从对话中学习偏好，自动反思改进 |
| 📚 知识增强 | 上传文档建立知识库，RAG检索增强回答精度 |
| 🛠️ 技能渐进 | 技能按使用频率逐步解锁，降低上手门槛 |
| 📝 文档生成 | 用自然语言生成/修改 Word、Excel、PPT 文档 |

### 四大核心能力

```
┌──────────────┐  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│  📝 文档引擎  │  │  📊 分析引擎  │  │  📤 OA/通知   │  │  🛠️ 智能工具  │
│  DocEngine   │  │  AnaEngine   │  │  Notifier    │  │  ToolBox     │
│              │  │              │  │              │  │              │
│ 自然语言→    │  │ 定时SQL查询→ │  │ 致远OA流程   │  │ 对话/OCR/    │
│ Word/Excel/  │  │ LLM分析→     │  │ 邮件/QQ通知  │  │ 搜索/计算    │
│ PPT          │  │ 自动生成报告  │  │              │  │              │
└──────────────┘  └──────────────┘  └──────────────┘  └──────────────┘
```

## 3. 安装部署

### 3.1 Linux一键安装

```bash
# 1. 将项目文件上传至服务器
cd /home/aide

# 2. 执行安装脚本
bash install.sh
```

安装脚本会自动完成：
1. ✅ 检查Python环境（缺失则自动安装）
2. ✅ 创建Python虚拟环境 `backend/venv/`
3. ✅ 安装后端Python依赖
4. ✅ 安装前端依赖并构建（需要npm）
5. ✅ 生成 `.env` 配置文件模板
6. ✅ 生成启动/停止脚本和systemd服务文件

> **提示**：如果服务器没有npm，前端构建会跳过。可先在有网络的机器上构建好再上传。

### 3.2 Windows安装

```
1. 双击 install.bat 运行
2. 等待安装完成
3. 编辑 backend\.env 配置文件
4. 双击 start_backend.bat 启动
```

### 3.3 离线安装

项目提供 `build_offline.sh` 脚本，可在联网环境打包离线安装包：

```bash
bash build_offline.sh
# 生成: aide-offline-v0.2.tar.gz
```

将离线包拷贝到目标服务器解压后执行 `install.sh` 即可，安装脚本会优先从本地 `packages/` 目录安装依赖。

## 5. 首次配置

### 5.1 编辑配置文件

安装完成后，**必须先配置** `backend/.env` 文件：

```bash
vim /home/aide/backend/.env
```

### 5.2 必填项

```env
# 选择LLM供应商（vllm / tencent / openai / custom）
LLM_PROVIDER=vllm

# ===== 根据选择的Provider填写对应配置 =====

# vLLM（内网部署，无需API Key）
LLM_BASE_URL=http://192.168.1.100:8004/v1
LLM_API_KEY=not-needed
LLM_MODEL=qwen3.6-27B

# 达梦数据库（如需数据分析功能）
DM_HOST=192.168.1.10
DM_STANDBY_HOST=192.168.1.11
DM_PORT=5236
DM_USERNAME=dmdb
DM_PASSWORD=你的数据库密码
DM_DATABASE=lczx
```

### 5.3 可选项

```env
# 邮件通知
EMAIL_SMTP=smtp.qq.com
EMAIL_SMTP_PORT=465
EMAIL_SENDER=xxx@qq.com
EMAIL_PASSWORD=你的邮箱授权码

# 致远OA
SEELYON_BASE_URL=http://OA地址:端口
SEELYON_USERNAME=你的OA账号
SEELYON_PASSWORD=你的OA密码

# 修改监听端口（默认8900）
PORT=8900
```

### 5.4 配置生效

修改 `.env` 后需要**重启服务**才能生效：

```bash
./stop.sh && ./start.sh
# 或
sudo systemctl restart aide
```

> **例外**：LLM模型切换支持运行时热切换，无需重启，详见[第15章](#15-llm模型切换)。

## 7. 智能对话

### 7.1 基本对话

在「💬 对话」页面的输入框中直接输入消息，按回车或点击发送：

```
你：帮我解释一下涡扇发动机的工作原理
知行：涡扇发动机由风扇、压气机、燃烧室、涡轮和尾喷管组成……
```

对话支持**流式输出**（SSE），AI的回复会逐字显示，无需等待全部生成完毕。

### 7.2 开启新对话

- 点击顶部「新建对话」按钮
- 左侧对话列表会显示历史对话记录

### 7.3 上传文件

点击输入框左侧📎按钮，可上传文件作为对话上下文：

**支持的文件格式：**
- 文档类：`.docx` `.xlsx` `.pptx` `.pdf`
- 文本类：`.txt` `.md` `.csv` `.json` `.yaml`
- 图片类：`.png` `.jpg` `.gif` `.bmp` `.webp`（支持OCR识别）

**使用场景：**
```
（上传一份PDF技术规范）
你：总结这份文件的关键要点
知行：（基于文件内容生成摘要）
```

### 7.4 关联知识库

发送消息时可选择关联的知识库，助手会先从知识库检索相关内容，再结合上下文回答：

```
你：【关联了"公司制度"知识库】我们的差旅报销标准是什么？
知行：（从知识库中检索到差旅制度相关内容后回答）
```

### 7.5 对话历史管理

| 操作 | 说明 |
|------|------|
| 查看历史 | 左侧对话列表 |
| 搜索对话 | 对话列表上方搜索框 |
| 删除对话 | 对话右上角删除按钮 |
| 生成摘要 | 对话详情页 →「摘要」按钮（每20轮自动生成） |

## 8. 文档生成

### 8.1 创建文档

**通过对话创建：**
```
你：帮我生成一份设备运行月报，包含概况、故障统计、维护建议三个章节
知行：已为你创建文档《设备运行月报》，包含以下内容：
  一、设备运行概况
  二、故障统计分析
  三、维护建议
  点击下载Word文件 📥
```

**通过文档页面创建：**
1. 点击「📝 文档」→「新建文档」
2. 输入文档类型（Word/Excel/PPT）和描述
3. AI自动生成文档内容

### 8.2 文档类型

| 类型 | 扩展名 | 支持内容 |
|------|--------|----------|
| Word | .docx | 段落、标题、表格、图片、图表、样式 |
| Excel | .xlsx | 数据表格、公式、图表、样式 |
| PPT | .pptx | 幻灯片、标题、内容、图表、布局 |

### 8.3 多轮修改

文档支持渐进式修改，不需要每次重新描述全部内容：

```
你：把第二段改成以数据驱动的描述方式
知行：已修改，增加了运行时长、故障率等数据支撑。

你：在维护建议章节加一个饼图，展示各类故障的占比
知行：已添加饼图，包含机械故障40%、电气故障30%……
```

工作原理：
```
用户指令 → 读取文档当前状态(JSON) → LLM理解并修改 → 渲染器重新生成文件
```

### 8.4 下载文档

- 对话中直接点击下载链接
- 文档页面 → 文档列表 → 下载按钮
- API：`GET /api/doc/{id}/download`

### 8.5 文档模板

可在 `backend/templates/` 目录放置模板文件，生成文档时指定模板：

```yaml
output:
  template: "templates/monthly_report.docx"
```

## 9. 数据分析与定时任务

### 9.1 任务管理页面

点击「📊 任务」进入任务管理界面：

| 功能 | 说明 |
|------|------|
| 任务列表 | 查看所有已配置的分析任务 |
| 新建任务 | 创建定时数据分析任务 |
| 手动执行 | 立即运行一次（不等定时触发） |
| 编辑任务 | 修改SQL/Prompt/输出模板 |
| 执行记录 | 查看历史执行结果和日志 |
| 启用/禁用 | 临时暂停或恢复定时执行 |

### 9.2 创建分析任务

**通过页面创建：**
1. 点击「新建任务」
2. 填写以下配置项：

| 配置项 | 说明 | 示例 |
|--------|------|------|
| 任务名称 | 简明描述 | 每日设备运行报告 |
| 执行计划 | cron表达式 | `0 8 * * *`（每天8点） |
| 数据库 | 达梦数据库连接 | 默认使用.env配置 |
| SQL查询 | 要执行的数据查询 | `SELECT * FROM device_status WHERE ...` |
| 分析提示词 | 指导LLM如何分析数据 | "总结运行状况，指出异常设备……" |
| 输出格式 | 报告文件格式 | docx / xlsx / pptx / md |
| 输出路径 | 文件保存位置 | output/reports/ |
| 通知渠道 | 执行完成后通知 | 邮件/QQ/OA |

**通过YAML配置文件创建：**

在 `backend/tasks/` 目录下创建 `.yaml` 文件：

```yaml
name: "每日设备运行报告"
description: "从达梦数据库获取设备数据，AI分析后生成Word报告"
enabled: true

schedule:
  cron: "0 8 * * *"   # 每天8点

database:
  host: "192.168.1.10"
  standby: "192.168.1.11"
  port: 5236
  username: "dmdb"
  password: "ENC:xxx"  # 加密存储
  database: "lczx"

sql: |
  SELECT device_name, run_hours, fault_count, last_check_date
  FROM device_status
  WHERE record_date = CURRENT_DATE

prompt: |
  你是航空发动机维修工厂的设备分析专家。请根据以下设备运行数据：
  1. 总结整体运行状况
  2. 指出异常设备
  3. 给出维护建议
  
  数据：
  {{data}}

output:
  format: "docx"
  filename: "设备运行日报_{{date}}.docx"
  save_path: "output/reports/"

notify:
  enabled: false
```

### 9.3 任务执行流程

```
定时触发（或手动执行）
    ↓
连接达梦数据库（主库失败自动切备库）
    ↓
执行SQL查询，获取数据
    ↓
将数据填入Prompt模板
    ↓
调用vLLM进行AI分析
    ↓
选择输出模板/格式，渲染文档
    ↓
保存文件到output目录
    ↓
推送通知（如果配置了通知渠道）
```

### 9.4 数据库高可用

- 任务执行时优先连接主库 `DM_HOST`
- 连接失败自动切换到备库 `DM_STANDBY_HOST`
- 支持连接超时和重试配置

### 9.5 查看执行记录

- 任务详情页 →「执行记录」tab
- 显示每次执行的时间、状态、输出文件、错误信息
- 可下载历史生成的报告文件

## 10. 知识库

### 10.1 创建知识库

1. 点击「📚 知识库」→「创建知识库」
2. 填写名称和描述
3. 点击创建

### 10.2 上传文档

1. 进入知识库详情页
2. 点击「📤 上传文档」
3. 选择文件上传

**支持格式：** `.docx` `.xlsx` `.pptx` `.pdf` `.md` `.txt` `.csv` `.json` `.yaml`

上传后系统会自动：
1. 解析提取文本内容
2. 将文本分块（chunking）
3. 生成向量索引（embedding）
4. 存入本地数据库

### 10.3 使用知识库

**方式一：对话时关联**
- 发送消息时选择要关联的知识库
- 助手自动检索相关内容辅助回答

**方式二：API调用**
```json
POST /api/chat
{
  "message": "我们的报销流程是什么？",
  "kb_ids": ["知识库ID1", "知识库ID2"]
}
```

### 10.4 检索测试

1. 知识库详情页 →「🔍 检索测试」
2. 输入关键词或问题
3. 查看检索结果和匹配度
4. 根据结果调整分块策略

## 11. 技能系统

AIDE采用**渐进式技能披露**机制：技能按使用频率逐步解锁，降低新手上手门槛。

### 11.1 技能等级

#### Level 1 — 基础技能（始终可用）

| 技能 | 图标 | 说明 | 触发方式 |
|------|------|------|----------|
| 网络搜索 | 🌐 | 搜索互联网获取信息 | 对话中自动调用 |
| 计算器 | 🔢 | 数学计算 | 对话中输入算式 |
| 读取文件 | 📖 | 读取服务器本地文件 | "读取xxx文件" |
| 列出目录 | 📂 | 查看目录结构 | "看看xxx目录" |

#### Level 2 — 进阶技能（使用基础技能3次后解锁）

| 技能 | 图标 | 说明 | 触发方式 |
|------|------|------|----------|
| 生成文档 | 📝 | 生成Word/Excel/PPT | "帮我写一个XX文档" |
| 数据分析 | 📊 | 数据库查询+LLM分析 | "查询设备数据并分析" |
| 发送通知 | 📤 | 邮件/QQ/OA通知 | "发邮件通知XX" |
| 写入文件 | ✏️ | 创建或写入文件 | "把内容写到xxx文件" |
| 修改文件 | 🔧 | 查找替换文件内容 | "把xxx文件中的A改成B" |
| 定时任务 | 📋 | 创建/管理定时分析 | "每天8点生成XX报告" |
| OCR识别 | 🔍 | 图片文字识别 | 上传图片时自动触发 |
| Git操作 | 🐙 | Git版本控制 | "查看git状态" |

#### Level 3 — 高级技能（使用进阶技能5次后解锁）

| 技能 | 图标 | 说明 | 触发方式 |
|------|------|------|----------|
| 数据库查询 | 🗄️ | 直接执行SQL | "查询XX表的数据" |

## 17. 常见问题（FAQ）

**Q: 浏览器打不开页面？**
A：
1. 检查服务是否启动：`curl http://localhost:8900/api/health`
2. 检查防火墙是否放行8900端口
3. 如果是远程访问，确认 HOST 配置不是 127.0.0.1

**Q: AI回复报错"Connection refused"？**
A：检查vLLM服务是否正常运行，确认 `LLM_BASE_URL` 配置正确，可手动测试：
```bash
curl http://192.168.1.100:8004/v1/models
```

**Q: OCR识别报错？**
A：默认使用LLM视觉模型识别图片文字。如需更好效果：
```bash
source backend/venv/bin/activate
pip install paddleocr paddlepaddle
```

**Q: PDF解析失败？**
A：安装PDF解析库（任选其一）：
```bash
pip install PyMuPDF     # 推荐，速度快
pip install pdfplumber   # 表格识别好
pip install PyPDF2      # 轻量
```

**Q: 数据库连接失败？**
A：
1. 确认达梦数据库服务正常运行
2. 检查 `DM_HOST`、`DM_PASSWORD` 配置
3. 测试网络连通性：`telnet 192.168.1.10 5236`

**Q: 修改端口后无法访问？**
A：编辑 `backend/.env` 中的 `PORT=8900`，然后重启服务

**Q: 思考模型（如glm-5.1）回复太慢？**
A：思考模型会先推理再回答，调大max_tokens：
```env
LLM_MAX_TOKENS=16384
```

**Q: 前端构建失败？**
A：确保安装了Node.js（v18+）：
```bash
cd frontend
npm install --registry=https://registry.npmmirror.com
npm run build
```

**Q: 如何设为开机自启？**
```bash
sudo cp aide.service /etc/systemd/system/
sudo systemctl enable aide
sudo systemctl start aide
```

**Q: 如何清除所有数据重新开始？**
```bash
# ⚠️ 不可恢复，请先备份重要数据
rm /home/aide/backend/data/*.db
rm /home/aide/backend/data/system_prompt.json
# 重启服务生效
```

**Q: 如何备份系统数据？**
```bash
# 备份数据库和配置
cp -r /home/aide/backend/data/ /home/aide/backup/data_$(date +%Y%m%d)/
cp /home/aide/backend/.env /home/aide/backup/env_$(date +%Y%m%d)
```

## 18. 安全与注意事项

### 18.1 安全设计

| 安全措施 | 说明 |
|----------|------|
| 数据本地化 | 所有数据存储在本机，不外传 |
| 加密存储 | 数据库密码、API Key使用AES加密 |
| 网络隔离 | API服务默认绑定0.0.0.0但不应暴露公网 |
| 命令黑名单 | Shell执行拦截 `rm -rf /`、`mkfs`、`dd` 等危险命令 |
| 二次确认 | OA流程发起等敏感操作需确认 |
| 渐进授权 | 高危技能需累积使用后解锁 |

### 18.2 建议的安全加固

1. **反向代理**：使用Nginx反向代理，加上HTTPS和访问控制
2. **防火墙**：只开放必要端口（8900），限制来源IP
3. **VPN**：远程访问时走VPN而非直接暴露
4. **定期备份**：备份 `data/` 目录和 `.env` 配置
5. **日志审计**：定期查看系统日志，关注异常操作

### 18.3 操作红线

- ❌ 不要将服务直接暴露到公网
- ❌ 不要在 `.env` 文件中明文存储生产环境密码
- ❌ 不要随意执行来源不明的Shell命令
- ❌ 不要关闭命令安全黑名单
- ✅ 使用 `trash` 替代 `rm` 删除文件
- ✅ 重要操作前先备份
- ✅ 定期更新依赖修复安全漏洞
