# AIDE - AI智能助手

> 项目代号：AIDE (AI Desktop Engine) | 版本：v0.3.0  
> 知行合一，说到做到

本地部署的企业级AI办公助手，零外部依赖，适配Win7/Win10离线环境。

## ✨ 核心能力

- 🧠 **智能对话** — 多轮对话、流式输出、思考模式、工具调用
- 📁 **文件检索** — 自然语言搜文件，向量语义+关键词混合检索
- 📊 **数据分析** — 自然语言查数据库，自动生成SQL+图表
- 📄 **文档生成** — 自然语言生成Word/Excel/PPT
- 📚 **知识库** — RAG检索增强，上传文档即问即答
- 🔄 **智能体广场** — 对接滴普FastAGI工作流平台
- 📧 **通知系统** — 邮件/QQ/OA流程集成
- 🧬 **自我进化** — 自动反思+规则积累
- 💾 **记忆系统** — 长期记忆+对话摘要，跨会话记住你

## 🚀 快速开始

### Windows离线安装
```
1. 将离线包拷贝到目标电脑（如 D:\aide）
2. 双击 install.bat 等待安装完成
3. 双击 start.bat 启动
4. 浏览器打开 http://127.0.0.1:8900
5. 首次使用请在 设置 页面配置大模型API Key
```

### Linux (Ubuntu 24.04)
```bash
bash install.sh        # 安装依赖
./start.sh             # 启动服务
```

## 📂 目录结构

```
aide/
  ├── app/           程序代码（升级时覆盖）
  │   └── backend/
  │       ├── core/      核心模块（LLM/技能/记忆/索引/进化）
  │       ├── routers/   API路由
  │       ├── engines/   文档/分析引擎
  │       ├── notifiers/ 通知渠道
  │       ├── renderers/ 文档渲染器
  │       └── static/    前端构建产物
  ├── config/        默认配置（升级时覆盖）
  ├── data/          运行时数据（升级不碰！）
  ├── user/          用户自定义（升级不碰！）
  ├── output/        生成的文档（升级不碰）
  ├── docs/          文档
  └── logs/          日志
```

## ⚙️ 配置

| 文件 | 说明 | 升级时 |
|------|------|--------|
| `config/default.env` | 默认配置 | 覆盖 |
| `user/user.env` | 用户自定义（优先级最高） | **不覆盖** |
| `data/system_prompt.json` | AI人格/规则 | 不覆盖 |

## 🖥️ 环境要求

### 大模型（任选一种）

| Provider | 适用场景 | 配置项 |
|----------|---------|--------|
| 本地vLLM | 内网有GPU服务器 | LLM_BASE_URL |
| 腾讯TokenHub | 有外网环境 | LLM_TENCENT_API_KEY |
| OpenAI兼容 | 其他兼容服务 | LLM_OPENAI_API_KEY |
| 自定义 | 特殊API | LLM_CUSTOM_API_KEY |

### 数据库（可选）

- 达梦 / MySQL / PostgreSQL / SQLite
- 在 设置 → 数据源配置 中添加

### 运行环境

- Windows 7 SP1 (64位) / Windows 10 (64位)
- 无需安装Python（离线包自带运行时）
- 无需联网

## 🔒 安全

- 所有数据存储在本地，不外传
- 密码字段代码中为空，运行时从 `user/user.env` 读取
- 内网IP、个人邮箱等已从源码清除
- `.gitignore` 排除运行时数据（data/、logs/、user/、*.db）
